# BidLab · 拍卖生成实验室

一个面向教学与探索的交互式网站：在浏览器中训练条件生成对抗网络（cGAN），观察模型如何学习模拟拍卖中的估值与报价关系。

## 在线体验

GitHub Pages 部署完成后：<https://shentonyan.github.io/auction-gan-lab/>

## 功能

- 切换第一价格与第二价格拍卖规则
- 调整竞买人数、估值市场和报价噪声
- 在浏览器中训练 cGAN，查看生成器/判别器损失
- 对比估值—报价散点、报价折扣率分布与训练轨迹
- 将生成样本组成模拟拍卖，比较平均成交价与配置效率
- 提供逐步训练、暂停和重新生成市场

## 本地运行

这是一个静态网站，不需要安装构建工具。直接打开 `index.html` 即可；也可以用任意静态 HTTP 服务托管当前目录。TensorFlow.js 从 jsDelivr 加载，首次运行需要联网。

## 模型与演示边界

市场数据由页面内的模拟器生成。估值支持均匀、双峰和偏态分布；报价基于简化的私人价值拍卖基准并加入可调噪声。cGAN 学习的是这些模拟样本的条件联合分布。成交价和配置效率由生成的竞买者样本按所选机制清算计算。

这些结果用于理解模型和机制的交互，不代表真实市场预测，也不构成策略建议。真实数据分析需要先明确字段、机制假设和数据质量，并另行验证模型。
